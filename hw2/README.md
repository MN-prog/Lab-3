## Задание (часть 2 - код)

Использовать C++ не ниже 14 стандарта

#### На оценку не выше 8:
Разработать класс для работы с матрицами:  
* класс должен содержать конструкторы или методы для считывания и вывода матрицы из консоли и файла;  
* перегрузить оператор * для умножения матриц, умножения матриц и скаляров;  
* перегрузить операторы - и + для сложения и вычитания матриц;  
* перегрузить операторы != и == для проверки равенства двух матриц, а также равенства матрицы и скаляра;  
* разработать функции элементарных преобразований матрицы;  
* реализовать возможность решения системы линейных уравнений, считанной из файла, а также проверки 
полученного результата;    

**_формат входных данных для системы линейных уравнений_**:  
  a[1][1]x1 + a[1][2]x2 + ... + a[1][n]xn = b[1]  
  a[2][1]x1 + a[2][2]x2 + ... + a[2][n]xn = b[2]  
  .  
  .  
  .  
  a[m][1]x1 + a[m][2]x2 + ... + a[m][n]xn = b[m]      
  на вход будет передано 2 + m * (n + 1) значений, а именно размеры матрицы, затем m строк,   
  в каждой из которых n + 1 значение, отвечающее за коэффициенты _а_ и _b_

**_формат выходных данных_**:  
   общее решение исходной системы уравнений, выраженное вектор-слобцом в параметричской форме, пример:

   |  1 - x3 - x4   |
   |:--------------:|
   | -2 + x3 + 2*x4 |
   | x3             |
   | x4             |

#### На оценку 9-10 (при идеальном выполнении пунктов под оценку 8):  
* разработать функцию, возвращающую определитель матрицы;  
* перегрузить оператор ! для вычисления обратной матрицы;  
* реализовать возможность решения матричного уравнения первой степени, считанного из файла, а также проверки полученного результата;  

**_формат входных данных_**:    
  На вход передается две матрицы, которые соответсвтенно задают коэффициенты выражения _AX + B = 0_,    
  сначала передается кол-во строк/столбцов матрицы _A_, затем значения, аналогично для матрицы _B_    
  пример: 2 3 4 4 4 5 5 5 1 1 7 =>   

A =

| 4 | 4 | 4 |
|---|---|---|
| 5 | 5 | 5 |

B =

| 7 |
|---|

**_формат выходных данных_**:       
  Матрица определенного или параметрического вида

#### Дополнительная важная информация
+ Нельзя использовать контейнеры и алгоритмы STL
+ Решения рассматриваются ТОЛЬКО в векторном пространстве над полем ДЕЙСТВИТЕЛЬНЫХ чисел (ℝ)
+ На вход могут подаваться несовместные системы линейных уравнений, в таком случае выходные данные должны указывать,
  что система решений не имеет
+ Матрица равняется скаляру, если на ее главной диагонали стоят элементы равные ему, а остальные 0 пример:

| 3 | 0 | 0 |
|---|---|---|
| 0 | 3 | 0 |
| 0 | 0 | 3 |
